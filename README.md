###
Implementing ["Eulerian video magnification for revealing subtle changes in the world"](https://dl.acm.org/doi/10.1145/2185520.2185561) from scratch.

### Clone and install dependencies
``` 
git clone https://github.com/alessiopiroli/evm_from_scratch
pip install -r requirements.txt 
```

### Magnify
``` 
python magnify.py evm/config/evm_config.yaml data/input.mp4 magnified/magnified.mp4
```
